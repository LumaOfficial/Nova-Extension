# Nova-Extension
This is the official Chrome Extension for Nova AI. Currently in beta, this platform may be unstable and could pose security risks. It has been tested on Windows, Linux, and temporarily on macOS. All issues reported will be used as feedback to improve stability and safety. Our goal is to address these issues. Developed by Luma. The patched `nova-extension-2.0.0.zip` build was generated by Base44: a local reasoning engine, 186 curated study notes, Learn Lab quizzes with XP and streaks, Text Lab, personas and a command palette — still with no API keys or hosted model.
